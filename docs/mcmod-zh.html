创世神选块（World Edit Select）

创世神选块（英文名 World Edit Select，简称 WES）是一个 Fabric 客户端模组，把 WorldEdit 的方块指令变成可视化的方块选择器——而且它就长在聊天框里。

为什么需要它

用 WorldEdit 填方块时，指令通常长这样：

//set 50%minecraft:stone,30%minecraft:cobblestone,20%minecraft:oak_planks

要记住方块 ID、要算百分比、要保证加起来正好 100、还要拼对方括号里的方块状态。任何一处写错，服务器就回你一句「无法识别方块名称」。

WES 把这些活全接过去：在聊天框输入 //set ，面板弹出来，点方块、填百分比，确认后指令自动写好放回聊天框。

特点

  • 在聊天框里，不是另开界面：面板是浮层，聊天记录和输入行依然可见，可以边看别人说话边操作。
  • 不止 //set：WorldEdit 里所有需要方块图案的指令都支持，共 15 条，并且会按每条指令的真实参数顺序显示对应的输入框。
  • 支持方块状态：床、楼梯、原木这类带属性的方块，点「态」按钮可以选 part=head、facing=east、axis=y 等状态，只把和默认值不同的部分写进指令。
  • 指令更短：原版方块不写 minecraft: 前缀，只有模组方块才带命名空间。//set stone 和 //set minecraft:stone 在 WorldEdit 里完全等价，而聊天指令只有 256 个字符，方块一多，省下的前缀就是实打实的额度。
  • 百分比自动均分：只填一部分百分比，剩下的自动平摊到没填的方块上，不用自己算。
  • 搜索：按中文名或方块 ID 过滤，一千多个方块里秒找。
  • 不自动发送：生成的指令只写回输入框，可以先看一眼、改一改，自己按回车。

支持的指令

指令生成形式面板里的额外输入
//set//set <图案>—
//replace//replace <被替换方块> <图案>选择被替换的方块
//overlay//overlay <图案>—
//center//center <图案>—
//walls//walls <图案>—
//faces//faces <图案>—
//line//line <图案> <厚度>厚度
//curve//curve <图案> <厚度>厚度
//hollow//hollow <厚度> <图案>厚度（写在图案前面）
//sphere / //hsphere//sphere <图案> <半径>半径（支持 3,5,7 椭球写法）
//cyl / //hcyl//cyl <图案> <半径> <高度>半径、高度
//pyramid / //hpyramid//pyramid <图案> <尺寸>尺寸

//forest 和 //flora 不在支持范围内——它们的参数里只有密度和树木种类，不接受方块图案。

使用方法

  1. 打开聊天框，输入 //set （注意末尾有一个空格）
  2. 面板弹出，光标自动落在搜索框
  3. 在左侧点方块加入，再点一次移除
  4. 在右侧填百分比，或点「态」修改方块状态
  5. 点击「确认填充」，指令写回聊天框
  6. 按回车发送
操作效果
回车确认，把指令写进输入框
Esc关闭面板（聊天框保留）；在状态编辑页则返回上一层
滚轮滚动方块列表 / 已选列表
点击面板外关闭面板

安装与依赖

  • Minecraft 1.20.1
  • Fabric Loader 0.14 及以上
  • Java 17
  • WorldEdit 7.2 及以上（Fabric 版）

把 worldedit-fabric 和 wes-<版本>+mc1.20.1.jar 一起放进 .minecraft/mods 即可。

注意事项

  • 只需装在客户端。这是纯客户端模组，服务端装了没有任何作用，加载器会直接跳过。
  • 但服务端必须有 WorldEdit。WES 只负责拼出指令文本，真正执行的是服务器上的 WorldEdit；单人存档或开房间同理。
  • 需要有对应权限。你在服务器上得具备 worldedit.region.set、worldedit.region.replace 这类权限，否则指令发出去也只会报错。
  • 不修改任何游戏内容，不添加方块和物品，也不与服务器进行额外通信。
